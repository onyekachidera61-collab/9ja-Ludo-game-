# 9ja Ludo 🎲

A fully playable browser-based Ludo game built with HTML, CSS, and JavaScript.

## How to Play

Open `index.html` in any modern browser — no installation needed!

## Features

- 4 players: Red, Blue, Green, Yellow
- Real Ludo rules with captures, safe zones, and home stretches
- Roll dice, move tokens, capture opponents
- Sound effects via Web Audio API
- Mobile-friendly design

*Built with ❤️ for Nigerian game fans.*
